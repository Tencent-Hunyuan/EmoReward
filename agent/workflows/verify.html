Behavioral cases for the host tests

  • Different batch lengths fail before the scorer; output order matches sample IDs; independent metadata dictionaries retain current update_step and max_steps.
  • One scalar per sample, not emo_total plus its EQ alias or an unintended additional VideoAlign term. Non-finite output follows the explicit host failure policy.
  • Missing face, unavailable R1-Omni or failed VideoAlign reveals the actual active set and fallback. Assert support/weights from instrumentation, not merely a plausible final scalar.
  • Check phase-gate behavior before warmup, inside the ramp, and after full-on using the resolved configuration. Direct scorer defaults are 40/100 while run_emoreward.sh exports 50/140; they are not one universal recipe.
  • Compare adaptive and jit with a unit table under identical inputs. A calibrated table is finite, positive and bounded. Sparse regimes use default; absent tables are diagnosed; scoring never changes the table hash.
  • Sequence-parallel non-leaders do not duplicate heavy initialization or score computation. Group broadcast/gather preserves ordering and random/round-robin state is reproducible under the chosen ownership model.

Report as HTML

Complete the HTML handoff with statuses pass, fail, blocked, not_run, commands, observed values and artifact paths. Keep synthetic checks, real scoring and training evidence separate. If no hardware or weights were available, deliver the validated adapter plus explicit missing prerequisites; do not describe it as a validated model deployment. This repository contains no bundled pretrained RewardMemory table or guarantee of improvement on a new host.
