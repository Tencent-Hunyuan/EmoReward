# Agent kit maintenance

Read `index.html` as the integration router. Its embedded JSON registry identifies task routes and source snapshots. Detailed contracts and handoffs are HTML; `README.md` only holds the relocated repository map.

Keep SKILL.md files as concise, portable discovery entrypoints. Read only the linked task workflow needed for the current request. Target-project instructions and the user's task scope still apply when porting into another project.

When maintaining this kit, reconcile source changes before refreshing manifest hashes. Verify HTML links, source symbols, the example adapter and the offline audit. A static audit or fake-scorer test is not a model/training evaluation. Do not add a nested Git repository, auto-install skills globally, or turn documentation into an automatic training launcher.
