Scoring contract

Existing boundary

emo_reward_score(device, config=None) creates one reusable callable. Call it with (video_paths, prompts, metadata); it returns (scores, auxiliary). The batch scorer's auxiliary mapping is currently empty, so it is not a validity report.

reward_fn = emo_reward_score(device=device, config=config)
scores, auxiliary = reward_fn(video_paths, prompts, metadata)
reward_vector = scores["emo_total"]
Input or outputPorting requirement
video_pathsOrdered local video-file paths, not generator latent tensors or image tensors. Export/decode through the host's existing media boundary.
promptsSame batch length and order as paths, with host sample IDs preserved independently of filenames.
metadataOne independent dictionary per sample. Supply update_step (or the supported global_step/step aliases) and max_steps for the intended warmup. No progress metadata means step zero, which changes phase gating.
scoresMetric name → list of scalars. Select emo_total once; EQ is its alias after fusion. Through multi_video_score, metric names are prefixed (for example emo_reward_emo_total) and avg is the configured aggregate.
FailureThe scorer can emit NaN per failed sample. Validate output length and finiteness; use the host's explicit failure/masking policy instead of silently substituting neutral or zero rewards.

The upstream batch loop uses zip; a short prompts/metadata list can silently truncate scoring. The example adapter checks cardinality first.

Fusion invariants

a_k = w0_k × g_k × m_k
R_emo = sum(active positive-weight a_k × s_k) / max(sum(a_k), 1e-8)
R_total = (alpha × R_vid + beta × R_emo) / max(abs(alpha) + abs(beta), 1e-8)

Preserve the actual fallback order in ReflectionRewarder.reflect: positive-weight active providers, then motion if active, then available providers with base weights, then auxiliary channel alignment if present, otherwise zero. The compact formula alone does not specify these branches. With nonnegative alpha/beta, the total denominator is their sum. If VideoAlign is absent or fails, the code can retain the emotion/physics result; record that degraded mode.

Seven fusion providers: macro, micro, body, temporal, clip_autt, r1omni, motion. Chromatic and kinetic are auxiliary logged channels in the runtime fusion path. The nine-key analysis memory is a different calculation domain; do not inject two new fusion providers merely because they appear in TOOL_KEYS.

Provider weights and gates are applied only over valid/active support. Do not infer validity from a score of 0.5, a filename, or successful import. ReflectionRewarder.reflect exposes activity, gates, confidence, and fallback details internally; preserve or instrument those details at the host boundary when testing degraded operation. The batch output alone does not expose all those flags.

Lifetime and optimizer boundary

  • Create the scorer once per reward-owning worker, reuse it across batches, and record resolved configuration. Heavy model loading is lazy and may fail only on the first real score.
  • The SAGE integration only scores on sequence-parallel leaders and distributes results to the group. Preserve the host's corresponding ownership and ordering; do not initialize heavy providers on every rank by copying launcher assumptions.
  • Use the reward as a scalar signal to the host optimizer. Preserve the host's advantage normalization, group size, and KL handling. Generator updates do not imply reward-model updates.
  • If emo_total already includes VideoAlign, adding the same general-video reward again changes the objective. Either use that fused result once, or deliberately disable internal fusion and define the host mixture.
  • Random and round-robin policies have state and randomness; keep scorer lifetime and seed controls stable for comparisons.
